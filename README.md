# Production Schedule

Система интерактивного управления расписанием сотрудников и техники на съемочных проектах. 

Приложение спроектировано как высокопроизводительный инструмент для планирования с поддержкой виртуализации данных, кастомизации тем оформления и распределения доступов.

## Ключевые возможности

### Frontend
- **Высокопроизводительная сетка**: Виртуализированная таблица на базе `@tanstack/react-virtual` легко справляется с отображением сотен дней и десятков проектов одновременно.
- **Интерактивная навигация (Click-to-Scroll)**: Клик по любой ячейке даты автоматически центрирует экран на текущем дне (беря локальную дату из браузера).
- **Выделение текущего дня**: Вся строка текущего дня автоматически подсвечивается настраиваемым цветом (в соответствии с часовым поясом GMT+3).
- **Сложное позиционирование (Sticky)**: Заголовок таблицы и колонка с датами закреплены при прокрутке с корректным наложением слоев (z-index).
- **Сайдбар фильтрации и подсветки**: Позволяет мгновенно подсветить или отфильтровать ячейки по конкретному сотруднику, проекту или машине.
- **Глобальные настройки дизайна (Theme Editor)**: Встроенный редактор темы позволяет администраторам настраивать палитру сетки (выходные, типы смен: натура, павильон, склад, переезд, цвет свечения при наведении, цвет подсветки текущего дня).
- **Умное редактирование ячеек**: Модальное окно позволяет структурированно выбирать тип смены, прикреплять сотрудников, выбирать машины и дополнительные опции. Поддерживается обратная совместимость (автопарсинг) старых текстовых данных.

### Backend
- **База данных**: Интеграция с базой данных через **Prisma ORM** (по умолчанию SQLite, легко масштабируемый до PostgreSQL).
- **Транзакционная оптимизация**: Каскадное удаление проектов, машин и сотрудников оптимизировано с помощью `Prisma.$transaction` — пакетные обновления SQLite происходят за один дисковый цикл, что ускоряет каскадные удаления в 10–50 раз.
- **Права доступа**:
  - Панель администратора защищена авторизацией на JWT-токенах.
  - Линейный персонал получает доступ к своему персональному календарю (Staff View) по персональной Magic-ссылке с токеном авторизации.

## Технологический стек

- **Frontend**: React 19, TypeScript, Vite, CSS Modules, `@tanstack/react-virtual`, Axios, React Router.
- **Backend**: Node.js, Express, TypeScript, Prisma ORM, JWT, Bcrypt.
- **Сборка**: Поддерживается раздельная сборка в независимые директории (`dist/` для backend и `dist/` для frontend) с чистым исходным кодом.

## Установка и запуск

### 1. Запуск Backend и БД
1. Перейдите в директорию бэкенда:
   ```bash
   cd backend
   ```
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Создайте таблицы и примените миграции Prisma:
   ```bash
   npx prisma migrate dev --name init
   ```
4. Заполните базу тестовыми данными:
   ```bash
   npm run seed
   ```
5. Запустите бэкенд в режиме разработки:
   ```bash
   npm run dev
   ```
   Сервер запустится на порту `3000`.

### 2. Запуск Frontend
1. Перейдите в директорию фронтенда:
   ```bash
   cd frontend
   ```
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Запустите клиент в режиме разработки:
   ```bash
   npm run dev
   ```
   Приложение будет доступно по адресу `http://localhost:2626`.
