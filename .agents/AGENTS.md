## Модель данных

### Prisma-схема (SQLite)

- **`User`** — Администраторы (role=`ADMIN`, passwordHash) и сотрудники (role=`STAFF`, accessToken).
- **`ProjectColumn`** — Столбцы сетки (`id`, `name`, `order`). Каждый столбец — независимое «рабочее пространство».
- **`ScheduleDate`** — Одна запись на каждую дату (`date: YYYY-MM-DD`). Поле `data: Json` хранит всё содержимое ячеек этого дня по всем столбцам.
- **`Car`** — Машины (`label`, `color` — цвет hex).
- **`StudioSetting`** — Ключ-значение для хранения настроек темы.

### Структура поля `data` в `ScheduleDate`

```json
{
  "<column-id>": {
    "cellType": "project_start" | "shift" | "day_off" | "stop" | "",
    "text": "строка для отображения (генерируется автоматически)",
    "color": "#hex (цвет проекта или машины)",
    "projectName": "Название проекта (только для project_start)",
    "staff": ["Имя1", "Имя2"],
    "cars": ["🚗 Волга"],
    "dayType": "натура" | "павильон" | "склад" | "переезд" | "выходной" | "отсыпной" | "стоп",
    "options": ["погрузка", "разгрузка"]
  }
}
```

> **Важно:** В базе есть устаревшие (legacy) записи без поля `cellType` — они были импортированы из Google Sheets. Фронтенд обрабатывает их через автодетекцию (`detectLegacyCellType`).

## Логика сетки (DataGrid.tsx)

### Типы ячеек и их визуализация

| `cellType`        | Поведение                                                         |
|-------------------|-------------------------------------------------------------------|
| `project_start`   | Старт проекта. Ячейка заливается цветом проекта. Ниже по столбцу всё принадлежит этому проекту до ячейки `stop`. |
| `shift`           | Смена. Показывает персонал + тип локации + машины.               |
| `day_off`         | Выходной/Отсыпной. Заливается цветом из темы (`weekendColor`).   |
| `stop`            | Конец проекта. Закрывает активный проект в столбце.              |

### Ключевые вычисления

- **`activeProjectsContext`** (`useMemo`): O(columns × rows). Для каждого столбца вычисляет, какой проект активен в каждой строке (обходом сверху вниз). Используется для sticky-заголовков и project-glow эффекта. **Не пересчитывается при скролле** — только при изменении `rows` или `columns`.

- **`gridItems`** (`useMemo`): Плоский список виртуализируемых элементов — месячные заголовки + строки. Месяцы свёрнуты по умолчанию (кроме текущего или последнего).

- **Виртуализация**: `@tanstack/react-virtual`. Рендерятся только видимые строки.

### Sticky-заголовки проектов

Когда пользователь скроллит вниз, активный проект «прилипает» к верху колонки в виде цветного оверлея на заголовок. Логика: `topOriginalIndex` — первый видимый элемент типа `row` (не `month-header`).

### Свечение проектов (project glow)

Ячейки, принадлежащие проекту (`isCellInProject`), получают `inset box-shadow` в цвет проекта:
- Смены: `hex + '26'` (~15% opacity)
- Выходные: `hex + '1A'` (~10% opacity)

### Legacy цвета (старые импорты)

В `DARK_COLOR_MAP` хранится маппинг Google Sheets цветов → тёмные эквиваленты:

| Исходный цвет | Тёмный эквивалент | Значение                          |
|---------------|-------------------|-----------------------------------|
| `#fff2cc`     | `#5c4008`         | Смена (светло-жёлтый → тёмно-жёлтый) |
| `#f4cccc`     | `#5c1e1e`         | Стоп (светло-красный → тёмно-красный) |
| `#b6d7a8`     | `#1e4620`         | Зелёный → тёмно-зелёный          |
| `#cccccc`     | `#2c2c2e`         | Серый (машины) → тёмно-серый     |
| `#efefef`     | `#1c1c1e`         | Пустой placeholder → почти чёрный |

## Фронтенд — правила разработки

### Стилизация
- **Только чистый CSS / CSS Modules**. Tailwind CSS запрещён.
- CSS-переменные темы: `--cell-bg`, `--panel-bg`, `--text-primary`, `--grid-border` и т.д. определены в `index.css`.
- Динамические переменные (цвета темы смен) передаются через инлайновый `style` с CSS custom properties на корневом элементе `DataGrid`.

### Z-Index слои
| Элемент                          | z-index |
|----------------------------------|---------|
| `.dateCell` (sticky колонка дат) | 10      |
| `.monthHeaderRow`                | 19      |
| `.headerRow`                     | 20      |
| Ячейка "Дата" в заголовке        | 21      |
| Оверлей активного проекта        | 22      |

### Работа с датами
- Даты хранятся и сравниваются строго как строки `YYYY-MM-DD` — никаких `new Date(string)` для сравнений (риск сдвига таймзоны при парсинге ISO).
- «Текущий день» определяется через `formatTodayStr(new Date())` один раз при монтировании (`useMemo`).

### Управление столбцами
- Кнопка **«+ Добавить столбец»** находится в сайдбаре AdminBoard (снизу, под «Настройки дизайна»).
- Метод `handleAddColumn` вызывается через `gridRef.current.addColumn()` — `gridRef` передаётся из AdminBoard в DataGrid через prop.
- Кнопка **«✕ Удалить столбец»** встроена в каждую ячейку заголовка столбца.

### CellSettingsModal
- Заголовок = `дата — Название проекта` (с цветом проекта).
- Если активного проекта нет — по умолчанию открывается как `project_start`, доступен только этот тип.
- При выборе `project_start` необходимо выбрать проект из глобального списка (свободный ввод отключен).
- Если активный проект есть — доступны `shift`, `day_off`, `stop`.
- Смена (`shift`) требует обязательного выбора локации (`dayType`) — иначе блокируется сохранение.

## Бэкенд — правила разработки

### SQLite и транзакции
- При каскадных обновлениях (удаление сотрудника/машины/столбца) **всегда** накапливать операции в массив и выполнять через `await prisma.$transaction(updates)`. Последовательные `await` внутри цикла в SQLite работают в 10–50 раз медленнее.

### JWT
- Все эндпоинты `/api/schedule`, `/api/columns`, `/api/admin/*` защищены middleware `requireAdmin` (JWT-токен в заголовке `Authorization: Bearer <token>`).
- Staff View использует query-параметр `?token=<accessToken>` — без JWT.

### Компилированный JavaScript
- Backend компилируется в `dist/` (настройки `rootDir: src`, `outDir: dist` в `tsconfig.json`).
- Никогда не коммитить скомпилированные `.js` файлы в `src/`.

## Частые ошибки и как их избежать

1. **Белые ячейки**: Возникают, когда legacy `color` из Google Sheets (напр. `#cccccc`, `#efefef`) не добавлен в `DARK_COLOR_MAP`. Добавить маппинг или очистить данные в БД.

2. **Sticky-заголовок проекта исчезает при скролле**: Баг при использовании `gridItems[0].originalIndex` — нужно перебирать виртуальные элементы и брать первый с `type === 'row'`.

3. **Прокрутка к сегодня не работает**: При закрытом месяце нужно сначала открыть его через `setCollapsedMonths`, затем вызвать `scrollToIndex` с задержкой `setTimeout(..., 50)`.

4. **z-index конфликт заголовков столбцов со sticky-хедером**: Sticky `position` на заголовках столбцов (не `date`) должен быть `relative`, не `sticky`.
