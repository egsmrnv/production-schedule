# Правила для агентов (AGENTS.md)

- Проект `production-schedule` использует монорепозиторную структуру (`frontend` и `backend`).
- При локальной разработке фронтенд запускается на `http://localhost:2626`.
- Бэкенд работает на порту `3000`.
- При внесении изменений в БД используйте Prisma ORM.
- Основной стек фронтенда: чистый CSS / CSS Modules (запрещено использовать Tailwind и утилитарные фреймворки).
- Сетка расписания: `@tanstack/react-virtual`.
